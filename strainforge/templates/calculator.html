Method used

    Material library

    MaterialMaterial constant CWork hardening nTensile strength Rm

    Select a row to use that material. Rm in the table equals C·(n/e)n; the Ludwik curve kf = C·φn is used everywhere else.

    Method notes

    How the calculations are set up
    1. Total strain in the flow stress. Upsetting uses kf1 = C·(φ + φ0)n, so the pre-strain φ0 is included. Example: C = 777 N/mm², n = 0.164, φ0 = 0.05, d0 = 14, d1 = 24, h1 = 2.2, µ = 0.15 gives kf1 = 792 N/mm², F = 554.1 kN and W = 0.987 kJ.
    2. Specific deformation work counts φ0 once. a = C·[(φ+φ0)n+1 − φ0n+1]/(n+1) for every process.
    3. Cracking limit for the head. Surface strain ξ is limited to 75 % for flat heads and 85 % for spherical heads.
    4. Deformation grade shown for every upsetting step. Closed Upset and Pre-upsetting form report φ itself.
    5. Trap Extrusion pre-strain. Uses the φ0 you enter, or 0.05 when the field is empty. Trimming evaluates kf at φ = 0.8.
    6. Separate manual fields. The manual tensile strength (Cut off) and the K1 factor (Backward Extrusion) have their own fields, so the automatic values stay visible.
